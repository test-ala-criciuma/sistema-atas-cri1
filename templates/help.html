Guias Rápidos por Página

Dashboard

Visão geral das próximas reuniões, acesso rápido para criar atas e atalhos para seções importantes.

  1. Clique em "Criar Ata" para iniciar uma nova ata rapidamente.
  2. Use os cards para navegar para Discursantes, Configurações ou Ver Todas.
  3. Use o resumo para ter contexto rápido sobre as atas do mês.

Login

Como entrar no sistema e aproveitar as dicas visuais (campo de senha com botão para mostrar/ocultar).

  1. Preencha seu usuário e senha.
  2. Clique no ícone do olho para mostrar/ocultar sua senha (área alinhada na captura).
  3. Após o login, você verá os atalhos do Dashboard (captura "Depois do Login").

Criar Nova Ata

Selecione o tipo de ata e a data. Use a seleção de data para escolher o domingo desejado.

  1. Escolha Reunião Sacramental e a data do próximo domingo.
  2. Clique em Avançar para abrir o formulário de criação/edição.

Formulário Sacramental

Campos organizados em cards: dados principais, hinos, discursantes e ações rápidas.

  1. Preencha o tema, escolha hinos e adicione discursantes.
  2. Use Salvar nos cartões ou o botão Editar para alterar a ata inteira.
  3. Veja como os elementos se comportam em diferentes tamanhos (sticky header e botões de ação).

Configurações

Gerencie templates e informações da ala. Use os botões de ação no cabeçalho para criar ou editar modelos.

  1. Clonar templates padrão para sua ala quando não houver modelos.
  2. Editar templates via modal e visualizar alterações antes de salvar.
