Guias Rápidos por Página

Dashboard

Visão geral: crie atas, veja a próxima reunião e acesse seções principais.

  1. Criar Ata — botão no topo para abrir o fluxo de criação.
  2. Próxima Reunião — clique em Ver Detalhes para acessar a ata daquela data.
  3. Resumo — mostra estatísticas rápidas e atalhos para ações frequentes.

Dica: use o filtro de mês para navegar rapidamente entre períodos.

Login

Acesse sua ala com usuário e senha. Use o olho para verificar sua senha antes de enviar.

  1. Preencha Usuário e Senha.
  2. Clique no ícone 👁️ para alternar a visibilidade da senha (útil em telas pequenas).
  3. Após o login, verifique os atalhos do Dashboard e personalize seu fluxo.

A captura mostra o campo de senha com o botão do olho corretamente alinhado (corrigimos o alinhamento recentemente).

Criar Nova Ata

Escolha o tipo da reunião e a data correta (geralmente o próximo domingo).

  1. Selecione Reunião Sacramental em "Tipo".
  2. Escolha a data (campo Data) — use o seletor nativo do navegador em mobile.
  3. Clique em Avançar para abrir o formulário (você pode editar depois).

Observação: ao escolher uma data já existente, o sistema abrirá a ata para edição.

Formulário Sacramental

O formulário é dividido em seções para facilitar o preenchimento e a revisão.

  1. Preencha o Tema no topo do card principal.
  2. Em Hinos, selecione os hinos de Abertura/Sacramental/Encerramento.
  3. Adicione os discursantes nos campos Discursante 1 e Discursante 2.
  4. Use o botão Salvar dentro de cada card para persistir alterações rapidamente.

Dica: o header torna-se compacto em mobile para economizar espaço (sticky header) — verifique o comportamento ao rolar a página.

Configurações

Gerencie templates, informações da ala e outras preferências.

  1. Se não houver templates para sua ala, use a ação Clonar modelos padrão.
  2. Edite templates no modal e visualize antes de salvar (botão Editar).
  3. Use as estatísticas para checar quantas atas foram criadas por mês.

Nota: modais são otimizados para foco e acessibilidade — pressione Esc para fechar.
